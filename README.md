# Portfolio — ธีมฟ้า-น้ำเงินสว่าง

เว็บไซต์หน้าเดียว ภาษาไทยเป็นหลัก ออกแบบให้สบายตาและรองรับมือถือ

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ VS Code + Live Server
3. ต้องมีอินเทอร์เน็ตเพื่อโหลด Bootstrap, ไอคอน, ฟอนต์ และ Animation จาก CDN

## เพิ่มรูปภาพ
นำรูปไปไว้ใน `assets/images/` ตามชื่อที่แสดงในแต่ละช่อง เช่น `profile.jpg`, `project-meeting.jpg`, `project-website.jpg`, `project-it.jpg` และรูปกิจกรรมที่ระบุไว้ในหน้าเว็บ ภาพจะถูกโหลดอัตโนมัติเมื่อพบไฟล์

## แก้ไขสี
แก้ที่ `assets/css/blue-light.css` ซึ่งเป็นไฟล์ธีมใหม่และโหลดท้ายสุด

ตรวจสอบข้อมูลส่วนบุคคลก่อนเผยแพร่จริง
